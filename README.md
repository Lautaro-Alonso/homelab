# Homelab
Este repo contiene la documentacion de mi homelab y de mi red domestica.
La idea es registrar las configuraciones, diagramas y cambios importantes que voy haciendo, para poder consultar mas adelante.
Actualmente todo está corriendo en una mini PC con Proxmox. Dentro de Proxmox corre pfSense como router y firewall principal. Desde ahi manejo la segmentacion de VLANs y las reglas de comunicacion entre ellas.
